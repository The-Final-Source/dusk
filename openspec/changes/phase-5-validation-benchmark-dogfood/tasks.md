> Ordered by dependency. Trace observability is foundational (the audit reads it); the seeded fixture is the ground truth the audit + benchmark score against; the audit and benchmark follow; static analysis and the worked-example regression are independent measurement legs; CLI surfaces the lot; ecosystem skeletons are app-package work; the dogfood is last and longest-running (a ≥14-day calendar window — start it as early as its prerequisites allow and let it run while later tasks proceed); smoke + cohesive landing gates archival. **When §11.4 closes, v1 is landed.**
>
> Each task names its acceptance (capability spec scenario + plan slug P5-T*) and its Vitest test plan with explicit **determinism surface**. **Zero-model tasks** (the citation scorer, fixture machinery, static analysis, ring buffer, mirrors, report schemas, drift guards) are pure/structural. **Real-frontier-model tasks** (the audit, the benchmark sweeps, the flake characterization, the dogfood's real runs) run at `temperature: 0`, gated behind the correctness env-var per the Phase 2–4 convention, and follow the **pre-registered transport-failure amendment** (transport errors are null observations; two transport deaths fail the leg; assertion failures never classify as transport noise). The audit's own statistical protocol (pre-registered frozen bars, N≥10) supersedes the N=3 ≥2/3 convention for its surface. Scaffolding/wiring is unmarked.
