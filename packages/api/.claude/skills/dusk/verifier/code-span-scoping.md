# Scoping reading to focal + support claims

You read ~3–8 lines per aspect, not the whole function. Use the focal claimants
(the `@intent` lines for this aspect) as the thing being judged, and the
support claimants (`@intent-support` lines) as the structural context. Lines
participating in OTHER aspects are out of scope — do not read or reason about
them. If the evidence you were handed is insufficient, that is a scoping or
decoration defect to report, not a reason to read the whole body.
